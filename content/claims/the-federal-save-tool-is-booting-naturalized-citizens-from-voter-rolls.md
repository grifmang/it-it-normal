summary: >-
  The federal SAVE (Systematic Alien Verification for Entitlements) tool is a
  DHS database used by states to verify citizenship status. Multiple states have
  used SAVE data in 2024-2025 to identify and remove voters from registration
  rolls, with some naturalized citizens receiving removal notices or being
  removed, though states report these were cases where citizenship documentation
  had not been updated in the system rather than systemic targeting of
  naturalized citizens.

evidenceFor:
  - >-
    Multiple states including Texas and Alabama have used SAVE database queries
    to identify potential noncitizens on voter registration rolls in 2024-2025
  - >-
    Naturalized citizens in Alabama and other states have received notices
    stating they would be removed from voter rolls based on SAVE database
    information
  - >-
    The SAVE database does not automatically update when individuals naturalize,
    creating a lag where naturalized citizens may still appear in the system
    with previous immigration statuses
  - >-
    Civil rights organizations have documented specific cases of naturalized
    citizens being flagged for removal through SAVE-based verification processes
evidenceAgainst:
  - >-
    The SAVE tool itself does not automatically remove anyone from voter rolls;
    it is a verification database that states query and then make their own
    removal decisions
  - >-
    States using SAVE data have implemented processes requiring individuals to
    provide proof of citizenship before actual removal occurs, rather than
    automatic removal
  - >-
    The removals appear to stem from database lag in updating naturalization
    records rather than the tool being designed to target naturalized citizens
  - >-
    DHS describes SAVE as a verification tool for benefit eligibility, not a
    voter roll management system, and its use for voter verification is a state
    decision

whatThisMeans:
  - >-
    The SAVE database is being used by states as one tool in voter roll
    maintenance, but it contains outdated information for individuals who have
    naturalized since their last interaction with immigration systems
  - >-
    Naturalized citizens are receiving removal notices when states use SAVE data
    without accounting for the database lag, though states provide opportunities
    to submit citizenship proof before final removal
  - >-
    The characterization of SAVE as actively booting citizens is imprecise; the
    tool provides data that states use to initiate removal processes, but the
    actual removals result from state policies on how to use that data
  - >-
    The issue highlights tensions between state efforts to remove noncitizens
    from voter rolls and the technical limitations of federal databases that do
    not update in real-time when immigration status changes
