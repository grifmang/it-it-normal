summary: >-
  The Department of Homeland Security's SAVE (Systematic Alien Verification for
  Entitlements) system has been used by states to verify citizenship status for
  voter registration, and some naturalized citizens have been flagged for
  removal from voter rolls in multiple states. While documented cases exist of
  naturalized citizens being incorrectly flagged, the extent of removals and
  whether the system itself is systematically removing eligible citizens remains
  contested, with states describing these as preliminary flags requiring
  additional verification rather than automatic removals.

evidenceFor:
  - >-
    The SAVE system is a federal database operated by DHS that states have used
    to check citizenship status for voter registration purposes
  - >-
    Multiple states including Alabama and Texas have used SAVE data in voter
    roll maintenance activities that resulted in naturalized citizens receiving
    notices questioning their eligibility
  - >-
    Documented cases exist where naturalized citizens were flagged by SAVE-based
    verification processes and faced potential removal from voter rolls
  - >-
    Civil rights organizations have filed lawsuits challenging voter roll

evidenceAgainst:
  - >-
    The SAVE system itself does not directly remove voters from rolls; it

    verification processes
  - >-
    States using SAVE data have described the flags as preliminary matches
    requiring additional verification rather than automatic removals
  - >-
    Election officials in states using SAVE have indicated that flagged voters
    receive due process opportunities to verify citizenship before any removal
    occurs
  - >-
    The system was designed for benefits verification rather than voter
    eligibility determination, and matching issues may occur when used outside
    its intended purpose
